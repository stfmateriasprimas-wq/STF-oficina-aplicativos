# 🚀 STF GROUP · Sistema de Control de Desarrollo y Rendimiento TI

Plataforma ejecutiva y operativa para la supervisión en tiempo real del progreso de software, fases de desarrollo, control de integraciones y auditorías de calidad para **STF GROUP**.

- **Pantalla de Acceso**: [https://stf-oficina-aplicativos.vercel.app/login](https://stf-oficina-aplicativos.vercel.app/login)

---

## ⚙️ Características Principales
1. **Supervisión de Aplicativos en Tiempo Real**:
   - Medición ponderada del avance matemático (Requerimientos 10%, Wireframes 15%, Frontend 25%, Backend 30%, QA 10%, Producción 10%).
   - Monitoreo de SLA, plazos de entrega y estado de salud operativa (*En Tiempo* / *En Riesgo*).
2. **Control de Equipo & Desarrolladores**:
   - Tarjetas interactivas por cada programador (Jose Guzman, Juan David, Mocho, Esteban Escobar).
   - Métricas de efectividad de entrega a tiempo y calidad de código.
3. **Auditorías de Calidad (Super Admin)**:
   - Calificación de estabilidad técnica, usabilidad y pruebas QA.
   - Suma directa de puntos ponderados al aplicativo auditado.
4. **Base de Datos en Tiempo Real con Google Sheets**:
   - Registro automático de cambios de fases en `Avances_Fases`.
   - Asignación de tareas en `Tareas_Integraciones`.
   - Evaluaciones oficiales en `Auditorias_Calidad`.
   - Trazabilidad global en `Bitacora_Cambios`.
   - Snapshot completo del portafolio en `Estado_Sistemas`.

## 🔄 Despliegue Continuo Automático (CI/CD)
Este repositorio está conectado directamente a **Vercel**. Cualquier cambio confirmado (`git push`) en la rama `main` se compila y publica automáticamente en internet en cuestión de segundos.
